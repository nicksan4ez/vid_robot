VID_ROBOT
=========

Inline-бот Telegram для поиска, подготовки и отправки коротких видео.
Основной принцип: в обычных чатах появляются **только готовые видео**, все тяжелые операции выполняются в личке.

Ключевые возможности
--------------------
- Inline‑поиск: `@vid_robot <запрос>` — мгновенная выдача **готовых** клипов.
- Подготовка нового видео через YouTube‑поиск (Piped API) и `yt-dlp`.
- Загрузка своего видео по ссылке (YouTube / Shorts / TikTok / Instagram Reels / VK / Vimeo / X/Twitter / Reddit).
- Персональный TOP “Готовое” как у стикеров: сначала личные частые, затем глобально популярные.
- Ограничение длительности: **≤ 60 секунд**.
- Максимальная совместимость видео: MP4/H.264/AAC с faststart.
- Жалобы на видео с модерацией через `ADMIN_ID`.
- Админ-статистика: `/stat` и автосводка по расписанию (`/stat_schedule`).

Как выглядит UX
--------------
### 1) Inline без запроса
Пользователь вводит `@vid_robot` без текста → получает персональный TOP готовых видео.
Если личных данных мало — список дополняется глобально популярными.

Подписи:
- **Часто используемое** — персональные
- **Популярное** — глобальные

### 2) Inline с запросом
`@vid_robot кот смешно` → сначала показываются совпадения по кэшу (по запросам и по заголовку),
причём **личные результаты идут первыми**.

### 3) Поиск на YouTube (через Piped)
Кнопка “Найти и подготовить 🎬 ≈ 10 сек” ведёт в личку.
Далее пользователь выбирает ролик из inline‑выдачи `yt:` — и начинается подготовка.

### 4) Загрузка своего видео (YouTube/Shorts/TikTok/Instagram Reels/VK/Vimeo/X/Twitter/Reddit)
Кнопка “Загрузить свое” запускает сценарий:
1) бот просит ссылку  
2) проверяет длительность  
3) просит ключевые слова для поиска  
4) готовит видео и присылает в личку с кнопкой отправки в чат

Статусы выводятся **в одном сообщении**, с кнопкой отмены.

### 5) Обрезка готового видео
Кнопка `✂️ Обрезать` доступна:
- под готовым видео (вместе с `💬 Отправить в чат..` и `⌨️ Добавить теги`)
- в reply-клавиатуре (`✂️ Обрезать`)

Сценарий:
1) пользователь выбирает видео  
2) бот просит диапазон: `00-05` или `0-5`  
3) бот обрезает и отправляет предпросмотр с кнопками `✅ Подтвердить` / `❌ Отменить`  
4) при подтверждении бот обновляет исходное видео в базе (по тем же тегам и ID)

Ограничение прав:
- обычный пользователь может обрезать только видео, которое загрузил сам
- администратор (`ADMIN_ID`) может обрезать любое видео

Поиск в YouTube
--------------
- Источник: **Piped API** (`/search`)
- Первичная выдача — 20 результатов от инстанса.
- Если приходит `nextpage`, бот догружает результаты до `MAX_INLINE_RESULTS`.
- Shorts распознаются по полю `isShort=true` или по URL `/shorts/<id>`.

Установка
---------
Требования:
- Python 3.10+
- `ffmpeg` в системе
- `yt-dlp` доступен в `PATH`

Быстрый старт:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Создайте `.env`:
```bash
cp .env.example .env
```

Запуск:
```bash
python3 -m src.main
```

Docker
------
Сборка и запуск:
```bash
docker compose up -d --build
```

Остановка:
```bash
docker compose down
```

Переменные окружения
--------------------
Минимум:
- `BOT_TOKEN` — токен Telegram‑бота
- `PIPED_API_BASE_URL` — базовый URL Piped API

Полный список:
- `HELP_BUTTON` — текст кнопки помощи (Markdown)
- `ADMIN_ID` — Telegram user id администратора (получает жалобы)
- `DB_PATH` — путь к SQLite
- `DOWNLOAD_DIR` — временная папка для скачивания
- `MAX_INLINE_RESULTS` — лимит inline‑выдачи (готовые + YouTube)
- `POPULAR_INLINE_RESULTS` — размер списка “Готовое” без запроса
- `VID_ROBOT_EMPTY_TOTAL` — общий лимит выдачи при пустом запросе (`@vid_robot`)
- `YT_INLINE_RESULTS` — не используется (оставлено для совместимости)
- `MAX_CONCURRENT_JOBS` — максимальное число одновременных подготовок
- `PM_TOKEN_TTL_SECONDS` — TTL токенов перехода в личку
- `STAT_SCHEDULE_DEFAULT` — время автосводки для админа (`HH:MM`, локальное время контейнера)
- `STAT_SCHEDULER_TICK_SECONDS` — период проверки расписания в секундах
- `PIPED_TIMEOUT_SECONDS` — таймаут Piped
- `PIPED_DEBUG` — подробные логи Piped (`1/true`)
- `YTDLP_TIMEOUT_SECONDS` — таймаут `yt-dlp`
- `YTDLP_SOCKET_TIMEOUT` — socket timeout `yt-dlp`
- `YTDLP_COOKIES_FILE` — путь к cookies для `yt-dlp` (если нужны)
- `YTDLP_EXTRACTOR_ARGS` — дополнительные extractor-args (`youtube:...`)

Важно про cookies
-----------------
- Указывай **абсолютный путь** к файлу cookies.
- В Docker нужно смонтировать файл в контейнер и указать путь внутри контейнера.
- Если файл смонтирован read-only, бот копирует cookies во временный файл в `/tmp/vid_robot` и использует его для `yt-dlp`.
- `YTDLP_DEBUG` / `YTDLP_DEBUG_LINES` — отладка `yt-dlp`

Хранилище
---------
- SQLite находится в `./data` (в Docker — `/app/data`)
- Временные файлы в `/tmp/vid_robot`

Примечания
----------
- В чатах появляются **только готовые** видео.
- Все тяжелые операции происходят в личке.
- Если Piped‑инстанс нестабилен, замените `PIPED_API_BASE_URL` на другой.

Админская статистика
--------------------
- `/stat` — мгновенная сводка:
- количество видео (всего/готовых/заблокированных), отправок, загрузок, тегов
- пользователи (всего и активные за 24ч), жалобы по статусам, топ видео по использованиям
- текущее расписание автосводки
- `/stat_schedule` — показать текущее расписание
- `/stat_schedule HH:MM` — установить время ежедневной отправки
- `/stat_schedule off` — отключить автосводку
